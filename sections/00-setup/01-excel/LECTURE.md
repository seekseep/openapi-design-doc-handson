# Excel の準備

第 1 章では、マクロ入りの Excel ブック（`.xlsm`）を使います。開いてマクロを動かせるように準備します。

## 使える Excel

| 環境 | 使えるか | 補足 |
|---|---|---|
| Windows の Excel（Microsoft 365 / 2021 / 2019） | ◯ | 教材はこれを前提に書いています |
| Mac の Excel | △ | 動く想定ですが、ファイルへのアクセス許可を何度か聞かれます |
| Excel for the web（ブラウザ版） | ✕ | マクロは動きません |

会社の PC では、情報システム部門の方針でマクロが禁止されていることがあります。その場合は設定を変えず、個人の PC で参加してください。

## ダウンロードした ZIP のブロックを外す

インターネットから落としたファイルには、Windows が「インターネットから来た」という印を付けます。印の付いたブックのマクロは、Excel が **赤いバー「マクロの実行がブロックされました」** で止めます。

ZIP を展開する **前** に、次のように印を外します。

1. ダウンロードした ZIP を右クリックし、「プロパティ」を開く
2. 「全般」タブの下にある **許可する** にチェックを入れて「OK」
3. それから ZIP を展開する

:::notice[展開したあとで気づいたら]
展開した `.xlsm` を右クリック →「プロパティ」→ **許可する** でも外せます。ZIP で外しておけば、中のファイルすべてに効きます。
:::

- [潜在的に危険なマクロがブロックされました（Microsoft サポート）](https://support.microsoft.com/ja-jp/topic/0952faa0-37e7-4316-b61d-5b5ed6024216)

## マクロを有効にする

ブロックを外したブックを開くと、上に黄色いバー「セキュリティの警告 マクロが無効にされました」が出ます。**このハンズオンで配ったブックだと分かっているときだけ**「コンテンツの有効化」を押します。

「すべてのマクロを有効にする」に設定を変える必要はありません。マクロはファイルの削除や外部への送信もできるので、出所の分からないブックのマクロは有効にしないのが原則です。

- [Microsoft 365 ファイルでマクロを有効または無効にする（Microsoft サポート）](https://support.microsoft.com/ja-jp/office/12b036fd-d140-4e74-b45e-16fed1a7e5c6)

## 開発タブ（任意）

ハンズオンの操作はシート上のボタンだけで進められます。マクロの中身を見てみたいときは「開発」タブを出しておくと便利です。

「ファイル」→「オプション」→「リボンのユーザー設定」で、右側の一覧の **開発** にチェックを入れて「OK」。「開発」→「Visual Basic」（`Alt` + `F11`）でマクロのコードを開けます。

:::faq

### 黄色いバーが出ずに、赤いバーが出る

ZIP のブロックが外れていません。いったん Excel を閉じて、上の「ダウンロードした ZIP のブロックを外す」をやり直してください。

### 「コンテンツの有効化」を押し忘れた

ブックを閉じて開き直すと、もう一度黄色いバーが出ます。一度有効にしたブックは、次からは聞かれません（信頼済みのドキュメントになります）。

:::
